# Essential Git CLI Commands

## 1. git status

Shows the current state of the Git repository, including modified,
staged, and unstaged files.

## 2. git add

Stages changes so they can be included in the next commit.

Example:
git add README.md

## 3. git commit

Creates a snapshot of the staged changes and records a message
describing what was changed.

Example:
git commit -m "docs: update README"
